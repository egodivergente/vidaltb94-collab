# Catálogo

Además de [AXEL, AXEL Editor de vídeo, ALEXIA, NEXUS y NutriShift](PROJECTS.md), tengo estos proyectos y herramientas.

## Archivos, imagen y audio

| Proyecto | Qué hace |
| --- | --- |
| CreatorVault | Agrupa material creativo en sesiones y proyectos dentro de una bóveda local. |
| [CineVault 48](https://github.com/vidaltb94-collab/CineVault48) | Prototipo de galería temporal con retención, papelera y simulación. |
| DisAster | Organización de archivos en Android. La reconstrucción y las ediciones web se mantienen separadas. |
| Keyframe Sorter | Clasificación de imágenes y keyframes mediante categorías. |
| AudioTrim | Recorte de audio local, con WAV comprobado muestra a muestra. |
| Recortar Audio | Otro recortador con forma de onda; parser WAV y etiquetado de salida pendientes de corregir. |
| PhotoLayers Studio | Edición por capas, máscaras y segmentación. Amplía mediante interpolación y enfoque. |
| AXEL Music | Biblioteca de audio local, cola y listas, con edición para TV. |
| AXEL Stream | Sirve archivos y medios por HTTP en la red local. |
| AXEL Media TV | Reproductor multimedia para Android TV. |
