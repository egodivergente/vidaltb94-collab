# Egodivergente

Hago aplicaciones para Android y herramientas locales. Trabajo sobre todo con vídeo, archivos y agentes de IA; también tengo proyectos para organizar turnos, comidas y tareas.

## Código abierto

Tres apps Android con código público, licencia MIT, compilación automática en GitHub Actions y APK descargable:

| Proyecto | Qué es | Lo interesante |
|---|---|---|
| **[AXEL Editor de vídeo](https://github.com/egodivergente/corte)** · [APK](https://github.com/egodivergente/corte/releases/latest) | Editor de vídeo multipista con timeline, keyframes, color, LUT y rótulos. | Módulos JVM puros, ripple con reglas explícitas, undo por cambios invertibles y un solo grafo Media3 para previsualizar y exportar. |
| **[NutriShift](https://github.com/egodivergente/nutrishift)** · [APK](https://github.com/egodivergente/nutrishift/releases/latest) | Planificador de comidas para quien trabaja a turnos. | Lee los turnos del calendario, despensa por lotes, raciones con consumo reversible y Room con migraciones probadas. |
| **[CineVault 48](https://github.com/egodivergente/CineVault48)** · [APK](https://github.com/egodivergente/CineVault48/releases/latest) | Galería de imágenes que caducan a las 48 h. | Plazos en UTC que nunca adelantan un borrado, WorkManager, auditoría y modo simulación. |

## Todos los proyectos

- **[AXEL](PROJECTS.md#axel)** — Codex, Grok y Antigravity desde el teléfono, con archivos y herramientas Android.
- **[AXEL Editor de vídeo](PROJECTS.md#axel-editor-de-vídeo)** — Edición multipista con vídeo y audio vinculados, timeline y exportación.
- **[ALEXIA](PROJECTS.md#alexia)** — Biblioteca de imágenes, vídeos y audio por proyectos, accesible desde otras apps.
- **[NEXUS](PROJECTS.md#nexus)** — Modelos de imagen, vídeo y audio, opciones de generación y resultados en una misma app.
- **[NutriShift](PROJECTS.md#nutrishift)** — Menús que tienen en cuenta los turnos, la despensa y las raciones preparadas.
- **[AudioTrim](PROJECTS.md#audiotrim)** — Recortes de audio locales con tratamiento específico para cada formato.

También trabajo en **AXEL Drobe**, **AXEL Task**, **Despeja**, **ClipTree** y herramientas para TV. El [catálogo](CATALOG.md) recoge el resto.

Kotlin · Compose · Room · Media3 · Python · TypeScript
